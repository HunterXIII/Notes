# JS_EQ — файл для повторения (теория)

Короткий конспект: по 2 вопроса на каждый билет, только ключевые идеи.

---

## Билет 1
- Живые коллекции (`HTMLCollection`, некоторые `NodeList`) обновляются вместе с DOM; статические (`querySelectorAll`) — снимок на момент запроса.
- `fetch` резолвится даже при `404/500`; `reject` обычно только на сетевых ошибках, CORS или `abort`.

## Билет 2
- Detached DOM Tree: узел удалён из DOM, но жив в памяти, пока есть ссылки из JS.
- `Promise.all` падает на первой ошибке; `Promise.allSettled` ждёт всех и возвращает статусы.

## Билет 3
- `innerHTML` парсит HTML и может быть XSS-опасен; `textContent` работает только с текстом и обычно быстрее; `innerText` учитывает видимость и может вызывать reflow.
- `then` всегда возвращает новый промис: значение -> `fulfilled`, промис -> "усыновление", `throw` -> `rejected`.

## Билет 4
- `AbortController` одноразовый: после `abort()` сигнал навсегда aborted.
- Таймаут с `reject` без `abort` не отменяет реальный сетевой запрос, только "отменяет ожидание".

## Билет 5
- `onclick` — один обработчик; `addEventListener` — несколько + options (`capture/once/passive/signal`).
- Трёхцветный GC: white/grey/black; write barrier защищает от ошибки при записи `black -> white`.

## Билет 6
- Поколенческая гипотеза: большинство объектов живёт мало, поэтому New Space маленький и чистится быстро.
- `Promise.race` возвращает результат первого завершившегося промиса (успех или ошибка).

## Билет 7
- IndexedDB-транзакция активна ограниченное время текущего шага event loop; через async-границы легко стать неактивной.
- Minor GC (Scavenge) для молодых объектов, Major GC (Mark-Compact) для старых; promotion переводит "выжившие" объекты в Old Space.

## Билет 8
- `await` не блокирует поток: функция ставится на паузу, продолжение идёт через микрозадачу.
- Hidden Classes ускоряют доступ к свойствам; хаотичная форма объектов ломает оптимизацию.

## Билет 9
- В JS наследование прототипное: свойства ищутся по цепочке `[[Prototype]]`.
- В обычных функциях в `then` теряется `this`; лечится стрелкой, `bind`, `self = this`.

## Билет 10
- Чтение идёт по прототипной цепочке, запись обычно создаёт собственное поле (shadowing).
- V8 spaces: New/Old/Code/Map/LOS (+ RO); LOS для крупных объектов с особой политикой GC.

## Билет 11
- Классы безопаснее: нельзя вызвать без `new`, методы неперечисляемы, strict mode по умолчанию.
- Page mask: быстрый расчёт страницы памяти и card index для дешёвого write barrier.

## Билет 12
- В наследнике `super()` обязателен до `this`, иначе `ReferenceError`.
- Частые утечки: забытые listeners, интервалы/таймеры, замыкания с тяжёлыми данными.

## Билет 13
- `_field` — соглашение, `#field` — реальная приватность языка.
- New Space: bump-pointer; Old Space: free-list; lazy sweeping делает очистку постепенно.

## Билет 14
- `super.method()` опирается на `[[HomeObject]]`; это не просто "вызов от this".
- Для old->new ссылок используется write barrier + card table, чтобы не сканировать весь Old Space на каждом minor GC.

## Билет 15
- `Symbol.species` управляет тем, какого типа объект создают методы производных коллекций.
- Рендер — отдельная фаза event loop; бесконечные macrotask могут "задушить" кадры.

## Билет 16
- Композиция часто лучше наследования: меньше хрупкости и связности.
- Hoisting: function declaration доступна раньше; `var` -> `undefined`; `let/const` в TDZ.

## Билет 17
- `toJSON` позволяет контролировать сериализацию (например, убрать пароль).
- IndexedDB в Worker есть, потому что асинхронная; `localStorage` синхронный и блокирующий.

## Билет 18
- `for..in` перечисляет и унаследованные enumerable-свойства; для "своих" ключей — `Object.keys/entries`.
- Function declaration vs expression/arrow/generator отличаются по правилам hoisting.

## Билет 19
- `requestAnimationFrame` синхронен кадру и лучше для визуальных обновлений, чем `setTimeout(0)`.
- Worker имеет отдельный event loop/стек/очередь и не имеет прямого доступа к DOM.

## Билет 20
- `requestIdleCallback` для фоновой несрочной работы в "окна простоя".
- Batch-запись в IndexedDB лучше делать порциями; пул воркеров эффективнее, но сложнее координировать; `SharedArrayBuffer` усложняет модель памяти и GC.

## Быстрый словарик
- **HTML-парсер**: превращает HTML-строку в DOM-дерево.
- **Reflow (layout)**: пересчёт размеров/позиций элементов; дорогая операция.
- **Repaint**: перерисовка внешнего вида без изменения размеров/позиции.
- **Capture-фаза**: событие идёт сверху вниз к цели (`capture: true`).
- **Bubble-фаза**: событие идёт от цели вверх (поведение по умолчанию).
- **Macrotask**: `setTimeout`, события UI и т.д.
- **Microtask**: `Promise.then`, `queueMicrotask`.
- **Detached DOM**: узел удалён из страницы, но жив в памяти из-за ссылок.
- **Hidden Class**: внутренняя форма объекта в V8 для оптимизаций.
- **Write barrier**: механизм GC для учёта важных записей ссылок.
